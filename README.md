# メール予定アシスタント

Gmail と Google Classroom を1時間おきにチェックして、メールから予定を読み取って Google カレンダーに勝手に入れてくれるアプリ

「この差出人の、このキーワードのメールを、こう読む」っていうルールを自分で作れるから、学校の締切でもバイトのシフトでも予約メールでも使える

> [!WARNING]
> **読めるメールアカウントは1つだけ**
> GAS を置いた Google アカウントのメール・Classroom・カレンダーしか読めない。2つ以上のアカウントのメールをまとめて使いたいときは、片方のメールをもう片方に Gmail の自動転送でまとめる（学校や会社のアカウントだと、外への自動転送が禁止されてることもある）
>
> アカウントごとに GAS を作れば、それぞれ勝手にチェックしてカレンダーには入るけど、アプリとウィジェットでつなげるのは1つだけ

## できること

- Gmail と Classroom を1時間おきに自動チェック（30分・3時間にも変えられる）
- ルールを何個でも作れる。ルールごとに決められるのはこれ
  - 差出人（アドレスでもドメインでも。複数OK）
  - キーワード
  - 読み取り方（本文から日付を自動で拾う ／ 休講・補講の案内）
  - Gmail と Classroom のどっちを見るか
  - どのカレンダーに入れるか
  - すぐ登録するか、確認してから登録するか
  - 前の日の20:00にリマインドするか
- 1通のメールに複数のルールが当てはまったら、上のルールが優先
- Classroom の課題で期限があるやつは全部拾う（設定でオフにもできる）
- iPhone のホーム画面とロック画面にウィジェットを置ける

### ルールの例

| ルール | 差出人 | キーワード | 読み取り方 | 入れるカレンダー | 登録 |
|---|---|---|---|---|---|
| 学校の締切 | `@school.ac.jp` | 締切、提出期限 | 日付を自動で拾う | 学校 | 確認してから |
| バイト | `shift@baito.example.com` | シフト | 日付を自動で拾う | 個人 | すぐ |
| 休講・補講 | `info@school.ac.jp` | （なし） | 休講・補講の案内 | 学校 | すぐ |

### 休講・補講の案内

こういう形のメール（か Classroom のお知らせ）を読む

```
■ 〇〇専攻1年
科目：プログラミング基礎 (山田 先生)
・【休講】12/3 (1限, 2限) 教室: 101
⬇️
・【補講】12/10 (3限) 教室: 201
```

- アプリの「ルール」→「休講・補講のルールを追加」で作れる
- 専攻を入れたらその専攻の欄だけ、空ならぜんぶ読む
- 時限表を入れておけば時間つきで入る。入れてなければ終日
- 予定が変わったら、前のは【変更前】（グレー）、新しいのは【変更後】（オレンジ）になる
- 科目名に「＜テスト配信＞」があるやつは無視

## しくみ

```
Google Apps Script（GAS） … 1時間おきにメールをチェックしてカレンダーに入れる本体（自分のアカウントで動かす）
PWA                       … iPhone のホーム画面に入れて使うアプリの画面（このリポジトリの GitHub Pages）
Scriptable                … iPhone のウィジェット
```

GAS は自分の Google アカウントで動くから、見れるのは自分のメールとカレンダーだけ。iPhone の電源が切れてても勝手にチェックしてくれる

アプリの画面はみんな同じページを使えばいい。最初に自分の GAS の URL を入れるから、表示されるのは自分のデータだけ

## 入ってるファイル

| ファイル | なに |
|---|---|
| `index.html` | アプリの画面（PWA） |
| `manifest.webmanifest` | アプリの名前とアイコンの設定 |
| `icon-180.png` `icon-192.png` `icon-512.png` | アイコン |
| `gas/Code.gs` | GAS の本体 |
| `gas/appsscript.json` | GAS の設定 |
| `scriptable/widget.js` | ウィジェット |
| `relay/Relay.gs` `relay/appsscript.json` | 中継用の GAS（メインのアカウントで「全員」に公開できない人だけ） |

## 使い方

### 1. GAS を用意する

1. https://script.google.com で「新しいプロジェクト」を作る
2. 左の歯車（プロジェクトの設定）→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
3. エディタに戻って、2つ貼って保存
   - `コード.gs` の中身を全部消して `gas/Code.gs` を貼る
   - `appsscript.json` の中身を全部消して `gas/appsscript.json` を貼る
4. 上の関数のところで `setup` を選んで「実行」
   - 権限を聞かれたら許可（「確認されていません」って出たら「詳細」→「移動」で OK。自分のスクリプトだから大丈夫）
   - 実行ログに出る `TOKEN` をメモしておく
5. 右上の「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
6. 出てきた URL（`…/exec` で終わるやつ）をメモしておく

「全員」が選べなかったら（学校や会社のアカウントだとだいたいこれ）、下の「1.5 中継 GAS」もやる。アプリで入れる URL と TOKEN は中継 GAS のほうになる

### 1.5 中継 GAS（「全員」が選べない人だけ）

Google アカウントを2つ使う

- **メインのアカウント** … メールとかカレンダーを読みたいアカウント（学校でも会社でも個人でもいい）。1 の GAS はこっち
- **公開用のアカウント** … 「全員」に公開できる別の Google アカウント（ふつうの個人の Gmail とか）。中継 GAS を置くだけで、メールは読まない

本体の GAS はそのまま裏でメールチェックとカレンダー登録をして、5分ごとに公開用アカウントの中継 GAS に結果を送る。アプリとウィジェットは中継 GAS とだけ話す

```
本体GAS（メインのアカウント） ── 5分ごとに同期 ──▶ 中継GAS（公開用のアカウント・全員に公開） ◀── アプリ・ウィジェット
```

1. **公開用の** Google アカウントで https://script.google.com を開いて「新しいプロジェクト」
2. 歯車 →「appsscript.json を表示」にチェックして、`コード.gs` に `relay/Relay.gs`、`appsscript.json` に `relay/appsscript.json` を貼って保存
3. `setup` を実行して、ログに出る **アプリ用 TOKEN** と **本体GAS用 SYNC_KEY** をメモ
4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」（実行：自分、アクセス：全員）で、URL をメモ
5. **メインのアカウントの**本体 GAS に戻って、`コード.gs` の一番上にあるこの2行の `''` の中に貼って保存
   ```js
   const RELAY_URL = '';   // ← 4の中継 GAS の URL
   const RELAY_KEY = '';   // ← 3の SYNC_KEY（32文字）
   ```
   貼ったらこうなる（値は例）
   ```js
   const RELAY_URL = 'https://script.google.com/macros/s/AKfy…/exec';
   const RELAY_KEY = '3f9a1c07b2e84d6f9a0c5e1b7d2f8a46';
   ```
6. 本体の GAS で `setupRelay` を実行。ログに「中継GASと同期できました」って出たら OK
   - 貼った値は実行したときに保存されるから、あとで `Code.gs` を新しいのに差し替えても貼り直さなくていい

アプリで「追加」とか設定を変えたら、アプリの上ではすぐ変わるけど、カレンダーに入るのは最大5分後

### 2. iPhone にアプリを入れる

1. iPhone の Safari で https://（ユーザー名）.github.io/（リポジトリ名）/ を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから開いて、さっきの URL と TOKEN を入れて「接続する」（中継 GAS を使う人は、中継 GAS の URL とアプリ用 TOKEN）
4. 「ルール」で自分用のルールを作る（最初は「締切・テスト」のルールが1個だけ入ってる）

iPhone の「設定 → カレンダー → アカウント」に Google アカウントを入れておけば、iPhone のカレンダーにも出る

### 3. ウィジェット（使うなら）

1. App Store で Scriptable（無料）を入れる
2. 「＋」で新しいスクリプトを作って `scriptable/widget.js` を貼る
3. アプリの「設定 → ウィジェット」の URL をコピーして、スクリプトの一番上の `WIDGET_URL` に貼る
4. ホーム画面を長押し →「＋」→ Scriptable を追加して、ウィジェットを長押し →「ウィジェットを編集」でさっきのスクリプトを選ぶ

小さいサイズで未確認の件数を出したいなら、Parameter に `count` って入れる

## 注意

- このリポジトリにはトークンとか個人情報は入ってない。TOKEN は `setup` を実行したときに自分の GAS の中で作られる
- 接続の設定は自分の iPhone の中にだけ保存される
- トークン付きの URL は絶対に人に教えないで
- 日付の読み取りはルールで判定してるから、変わった書き方だと読み取れないことがある
- キーワードも差出人も空のルールは、広すぎるから Gmail では使われない
- `Code.gs` を書き換えたら、「デプロイを管理」→ 鉛筆 →「新バージョン」でデプロイし直さないと反映されない
- 前のバージョンを使ってた人は、`Code.gs` を差し替えるだけで今までの設定が自動でルールに変わる
